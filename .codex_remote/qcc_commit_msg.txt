Add depth correspondence QCC fusion branch

Achieved:
- Reproduced the fg83 depth baseline correctly at 83.61 top-1 / 96.47 top-5 after identifying that the earlier 76% readings came from horizontal flip TTA; no-TTA is the correct eval path for that checkpoint.
- Implemented a genuine quaternion cycle-consistency path over depth-derived correspondence pointclouds, without DSN pretraining.
- Best QCC correspondence run is depth_corr_qcc_f16p128: 16 frames x 128 points, 0.862M params, 61.83 top-1 / 86.31 top-5 standalone.
- Best fg83+QCC fused result is 84.65 top-1 / 96.27 top-5 at epoch 255, now published to experiments/work_dir/depth_small for the Anemon app.
- Also tested weaker 8x64 QCC fusion, failed 32x256 scale-up, and fg83 residual QCC; only the 16x128 correspondence branch gave a useful lift.

How:
- train_corr_qcc_fusion.py adds CorrQCCNet, a compact point-correspondence branch that uses normalized xyz, velocity, and first-frame displacement features with point MLP pooling, a temporal GRU, attention pooling, and a class head.
- The QCC branch computes Kabsch target quaternions from correspondence frames, predicts adjacent step quaternions and skip quaternions, and trains with class CE plus step/skip quaternion geodesic loss plus cycle loss where q_step[t+1] * q_step[t] must match q_skip[t].
- Fusion uses fg83 depth logits plus QCC branch log-probs with a small temperature/weight grid, then writes best fused logits back to the depth_small workdir for Anemon.
- train_depth_small.py carries the foreground-cropped depth baseline, correspondence cache builder, and reusable quaternion/Kabsch helpers used by the QCC branch.
- sidepanel_api/fusion_watcher.py now tracks depth_small alongside cnxxl, DSN, and M so the app reports the active QCC depth result.
- QCC_DEPTH_CORRESPONDENCE_STATUS.md documents active paths, implementation details, achieved scores, failed attempts, and the remaining >89 goal.
